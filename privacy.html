Prism — Privacy Policy

Last updated: October 5, 2026

Prism ("the app") is a personal, single-user desktop tool that runs locally on its owner's computer. It is not offered to the public.

1. Data the app accesses

  • TikTok basic profile (scope user.info.basic): open ID and display name, used only to show which account is connected.
  • OAuth tokens: the access and refresh tokens issued by TikTok, used to upload videos to the connected account's inbox (scope video.upload).

2. How data is stored

All data is stored only on the owner's computer, in local files readable by the owner's user account. There is no server, no database in the cloud, no analytics and no advertising.

3. Sharing

Data is never sold, shared or transferred to third parties. Video files are sent only to TikTok, through the official TikTok API.

4. Retention and deletion

Tokens are kept until the account is disconnected. Access can be revoked at any time in the TikTok app (Settings → Security → Apps and services); deleting the local token file removes all stored TikTok data.

5. Children

The app is not directed to children.

6. Changes

This policy may be updated; the date above shows the latest version.
